В дополнении к режимам прокрутки (`Scroll Mode`), улучшенной точности (`Sniper Mode`) и текстовому режиму (`Text Mode`) появились пользовательские режимы (`Mod User 1, 2, 3`), в каждом из которых можно назначить по четыре пользовательских комбинации для четырех направлений. В текстовом режиме также имеется возможность переопределить отправляемые комбинации (таким образом, всего имеется четыре пользовательских режима).

Для активации нового режима необходимо во вкладке Layout выбрать режим Led Blinks. Кроме этого, в этой вкладке теперь имеется чуть больше возможностей по конфигурированию трекболла.
